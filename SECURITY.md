# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in ResumeForge, please email us at erwinmustapha5@gmail.com instead of using the issue tracker.

Please include the following details:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

We will acknowledge your email within 48 hours and provide a status update on the vulnerability within 5 business days.

## Security Updates

We take security seriously and will:
- Respond to all security reports promptly
- Patch vulnerabilities as soon as possible
- Provide security updates and patches for all currently maintained versions
- Notify users about critical vulnerabilities

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | ✅ Yes             |
| < 1.0   | ❌ No              |

## Security Best Practices

When using ResumeForge:
- Keep your GitHub account secure with 2FA enabled
- Use strong, unique passwords
- Review what data you're sharing with the app
- Report suspicious activity immediately

Thank you for helping keep ResumeForge secure!
